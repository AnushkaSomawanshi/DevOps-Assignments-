# GyneCare Hospital MERN

MERN conversion of the original GyneCare project with:

- `client/`: React + TypeScript + Vite frontend
- `server/`: Node.js + Express + MongoDB + Mongoose backend

## Run locally

Backend:

```bash
cd server
npm install
npm run dev
```

Frontend:

```bash
cd client
npm install
npm run dev
```

MongoDB:

```text
mongodb://127.0.0.1:27017/hospitalDB
```
