# Troubleshooting Index

Status: `DOCUMENTED`

## Assignment 2: EC2

Potential issues include SSH timeout, wrong key permissions, restrictive security groups, an unavailable application port, missing environment variables, MongoDB connectivity, and a stopped Node process.

## Assignment 3: cloud services

Potential issues include S3 access denied, incorrect bucket policy, missing Lambda permissions, RDS network isolation, unhealthy load-balancer targets, and failed ECS tasks.

## Assignment 4: Docker

Potential issues include dependency installation failure, port conflicts, an invalid Dockerfile instruction, a container exiting immediately, a failed health endpoint, and incorrect network assumptions.

## Assignment 5: Terraform

Potential issues include missing credentials, invalid AMIs, wrong regions, missing key pairs, provider version constraints, state locks, and plan dependency errors.

These are potential failure modes, not observed incidents. Observed issues will be recorded with command output and date after execution.
